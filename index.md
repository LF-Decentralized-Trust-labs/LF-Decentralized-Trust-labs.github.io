# LF Decentralized Trust Labs

LF Decentralized Trust Labs provides a space (i.e., GitHub repos) where work can
easily be started without the creation of a project. Labs are a home for
early-stage work — a place to build community, contribution, and momentum before
a project is mature enough to stand as a top-level LFDT project.

This site lists the [approved](labs/) and archived labs and documents
[labs governance](governance). It is built from the
[lf-decentralized-trust-labs.github.io](https://github.com/lf-decentralized-trust-labs/lf-decentralized-trust-labs.github.io)
repository.

## Process to propose a new lab

**To propose a lab, [open a Lab Proposal issue](https://github.com/LF-Decentralized-Trust/lab-proposals/issues/new?template=lab-proposal.yml)
in the [lab-proposals](https://github.com/LF-Decentralized-Trust/lab-proposals)
repository.** Filling out that form is the entire submission.

> **Note:** This replaces the previous process of forking the
> [site repository](https://github.com/lf-decentralized-trust-labs/lf-decentralized-trust-labs.github.io),
> writing a `[labname].md` proposal from a template, and opening a pull request. You no
> longer need to do any of that, and the proposal template has been retired.
> Every proposal comes in through the form so that stewards see the same
> information for every lab.

Read the [lab-proposals README](https://github.com/LF-Decentralized-Trust/lab-proposals/blob/main/README.md)
before you file; it covers the whole process in detail.
