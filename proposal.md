# Original Labs Proposal

The original 2018 proposal that created Hyperledger Labs used to live here. It
described the organization, bodies, and processes as they were at the time, none
of which reflect how labs work today. It remains in this repository's git
history.

To propose a lab, [open a Lab Proposal issue](https://github.com/LF-Decentralized-Trust/lab-proposals/issues/new?template=lab-proposal.yml)
in the [lab-proposals](https://github.com/LF-Decentralized-Trust/lab-proposals)
repository. See [Process to propose a new lab](index#process-to-propose-a-new-lab)
and [Labs Governance](governance) for the current process.
